dademain.exe - 极域工具箱（重实现）

这是从 FUCKUPXdademain.c（Ghidra 反编译导出）逆向分析后重写出来的 可编译版本，仅保留原程序的启动器骨架：自解压、配置驱动、提权、菜单执行。

免责声明：本工程用于逆向工程学习与代码质量研究。请勿用于未经授权的机器。

它做了什么

  1. 在 exe 同级创建 dade\ 目录；
  2. 首次运行写 eula.txt 并显示本页面；
  3. 按内置资源 TOOLS_MANIFEST 把载荷释放到 dade\；
  4. 解析 dade\.dade，把 [工具:*] 段渲染成菜单；
  5. 选中后按配置启动外部程序：可要求管理员、可隐藏窗口、可交互填参数。

目录结构

<exe 所在目录>\
├─ dademain.exe
├─ eula.txt                 首次运行生成
└─ dade\
   ├─ .dade                 工具清单（从内置资源释放，可手工修改）
   ├─ .version              "1.0.0.0"，决定是否重新解压
   ├─ readme.html           本页面
   └─ tools\hello.bat       示例载荷

菜单命令

输入作用
序号执行对应工具
0子菜单里返回上级
r / reload重新读取配置
!r / restore清空 .version 并重新解压（会覆盖 .dade）
h / help / ?打开本页面
q / Q / exit退出

配置格式

[工具:分组名]

[工具段名]
name=显示名
desc=描述
path=tools\hello.bat
args=/{名字}
workdir=tools
newconsole=1
wait=1
prompts=名字:世界

prompts 定义交互参数，格式 题面:默认值;题面2:默认值2； args 里的 {题面} 会被替换成用户输入。
